后记

一部可以日日使用的经

三十二分读毕，回看一遍，会发现一件事：

《金刚经》几乎把人类能执着的每一样东西，都破了一遍。

破财（第四、八、十一、十九分）——你以为是钱。

破身（第三、十三、十四分）——你以为是命。

破果（第九、二十二分）——你以为是修行成就。

破土（第十分）——你以为是你的世界。

破相（第五、二十、二十六分）——你以为是佛。

破言（第二十一分）——你以为是真理。

破心（第十八分）——你以为是你自己。

破见（第三十一分）——你以为是你对。

破空（第六、二十七分）——最后连"我什么都没执着"这个念头也破掉。

而破完之后，经中没有留下一个"空"。它留下的是第三十二分那八个字：不取于相，如如不动。

这八个字，不是终点，是起点。

因为从第一分到第三十二分，佛做的每一件事，都在演示它——他穿衣、乞食、洗足、落座、说法、沉默，无一处取相，无一处不生动。

## 这一部书的用法

不要把它当研究材料。

研究材料读完了会合上；这部经读完了要打开——打开在第二天早上起床时。

遇到具体烦恼时，按图索骥。

  • 觉得自己做了很多好事而没人看见 → 读第四分、第十九分、第二十八分。
  • 觉得自己修行有进步 → 读第九分、第十七分、第二十二分。
  • 觉得这世界太假、什么都不想管 → 读第二十三分、第二十七分。
  • 觉得一切皆空、可以随便 → 读第二十七分、第三十分。
  • 打坐见到光、见到佛、见到空 → 读第二十六分、第二十分。
  • 读了很多经、懂了很多道理、开始评判别人 → 读第三十一分。
  • 被人伤害、受了委屈、想不通 → 读第十四分。
  • 一直很努力但境界不见起色 → 读第十六分。

每日一句，胜过通读一遍。

把一句话带在身上，遇境即提，比读完全书而一句不落地用，要强得多。

## 关于"三十二分"的最后一句

昭明太子的分题，是路标。

路标的好处是：让你知道走到哪儿了。

路标的坏处是：容易让人以为路标就是路。

所以全书每一分，都重复了同一句提醒：三十二分标题为后世科判，非经文原有，不可执为经之本体。

这不是形式上的免责，是内容上的必要。

因为《金刚经》第三十一分说得很清楚——所言法相者，即非法相。

连"《金刚经》三十二分"这个框架本身，也在这个句式之内。

读到最后，若还留着一个"我已经把《金刚经》读懂了"的念头，那就还差最后一步：

把这个念头，也放在"即非"里过一遍。

过了这一遍，才是真的读完。
