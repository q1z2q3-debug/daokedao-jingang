这本书主张什么

「即非」不是否定，是不执。读成"其实没有这回事"，就滑向断灭空，废因果、废修行、废慈悲——这是本经自己反复警告的坑（"法尚应舍，何况非法"正为此设）。「即非」破的只是"把它当成固定实有的东西抓在手里"，不破它缘起的作用。

正宗分二十九分，须菩提两问（云何应住、云何降伏其心），佛陀一路只答一件事——应无所住而生其心。二十九分，都是在从不同角度拆解"住"这个字。

体例：一分七段

原文底本、分题释义、字源与名相、逐段深解、俗见勘破、般若范式与跨典互参、小结。凡「如来说〇〇，即非〇〇，是名〇〇」，单列三层：随俗安立／胜义破除／二谛圆融。底层模型为「三才五蕴太极空杯」，并以老庄、易传、儒门互参。
