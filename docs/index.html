金　刚　般　若

《金刚般若波罗蜜经》三十二分通释
一切有为法，如梦幻泡影，
如露亦如电，应作如是观。
读全书 仓库 Markdown 母本

这本书在做什么

全书只做一件事：把「佛说 A — 即非 A — 是名 A」这把尺子，逐分拆开，让经文自己把般若讲出来。不取玄虚之说，不做宗教附会，落到「人如何不被自己的念头困住」。

七万八千字，三十二分，一分七段。原文用鸠摩罗什译本；每一分都标明：三十二分的分题是梁昭明太子所科，非经文原有，是研读的路标，不是经之本体。

有一个字要先讲透：「即非」不是否定，是不执。读成"其实没有这回事"，就滑向断灭空，废因果、废修行、废慈悲——这是本经自己反复警告的坑（"法尚应舍，何况非法"正为此设）。「即非」破的只是"把它当成固定实有的东西抓在手里"，不破它缘起的作用。

三分判摄

  • 序分　第一分法会因由、第二分善现启请。立教起因、当机者、提问。
  • 正宗分　第三分至第三十一分。破四相、破法执、明无住、辨福德、显实相。
  • 流通分　第三十二分应化非真。收束全经，咐嘱流通。

正宗分主线只有一句：须菩提两问——云何应住、云何降伏其心；佛陀一路只答一件事——应无所住而生其心。二十九分，都是在拆解"住"这个字。
