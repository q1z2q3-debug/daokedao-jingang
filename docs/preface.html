# 润泽说 道可道之金刚经

## 《金刚般若波罗蜜经》通释

体例与总纲

一、为什么下一步是《金刚经》

《心经》通释从头到尾，用的一把尺子就是佛说A—即非A—是名A。

这把尺子的源头，就在《金刚经》。《心经》是这把尺子的浓缩应用；《金刚经》是这把尺子的全程展开。

所以顺序上是倒过来的：先用心经练手，再回金刚经立总纲。此后坛经、儒门，乃至回看周易老庄，全部可以挂在这把尺子上。

两经分工，一句话：心经是纲，二百六十字摄一切；金刚经是目，三十二分句句拆解「如何不住」。

二、全书体例（六段，另加一项）

每一分统一按六段展开：

1. 原文底本（鸠摩罗什译本，保留通行字句，异读另注）

2. 分题释义（昭明太子三十二分标题的字面与义理，标题非经，须标明）

3. 字源与名相（梵文原词、汉译流变、古义勘正）

4. 逐段深解（本分核心义理，逐句落地）

5. 俗见勘破（列三至五条常见误读，逐条正解）

6. 般若范式 + 跨典互参（三段论拆解；老庄、易传、儒门对照）

新增一项，金刚经特有：三段论逐句拆解。

凡经中出现「如来说〇〇，即非〇〇，是名〇〇」句式，单列一小节，拆成三层：

  • 随俗安立（佛说A）：依世间共许，假名施设，不废言说、不废因果、不废修行。
  • 胜义破除（即非A）：于实相中，此A无自性可得，破的是"执A为实"，不是破A的作用。
  • 二谛圆融（是名A）：不坏假名而契实相，行于世间而不着世间。

这里要提前把最容易被讲错的一处讲透：「即非」不是否定，是不执。

很多人把「即非」读成"其实没有这回事"，于是滑向断灭空，废因果、废修行、废慈悲，这是《金刚经》自己反复警告的坑（后文"法尚应舍，何况非法"正是为此设）。「即非」破的只是"把它当成固定实有的东西抓在手里"这一层，不破它缘起的作用。

三、全书结构（三分判摄）

  • 序分：第一分法会因由、第二分善现启请。立教起因、当机者、提问。
  • 正宗分：第三分至第三十一分。破四相、破法执、明无住、辨福德、显实相。
  • 流通分：第三十二分应化非真。收束全经，咐嘱流通。

一句话把握正宗分的主线：须菩提三问（云何应住、云何降伏其心），佛陀一路只答一件事——应无所住而生其心。全经二十九分，都是在从不同角度、针对不同执着，拆解"住"这个字。

四、关于底本与科判

底本。 本书原文采用姚秦鸠摩罗什译本，即千年流通的通行本。玄奘译本（《大般若经》第九会）文相较详，可作对读，但本书不杂入，以免两本文句互串。

科判。 三十二分的分题，是南朝梁昭明太子萧统所作，属于后世科判，并非经文原有。本书每分均标明此点。分题是研读的路标，不是经之本体；把分题当成佛说，是另一重"法相"之执——这一点，恰是第三十一分"知见不生"所破。

校记。 原稿第一至十二分中，第六、七、八三分的分题与所标经文互相错位：第六分「正信希有」下所载，实为第七分「无得无说」经文；第七分「无得无说」下所载，实为第八分「依法出生」经文；第八分「依法出生」下所载，实为第十八分「一体同观」经文（五眼与三心不可得）。

本次成书按经序归位：第六分另补「正信希有」本分经文（一念净信、法尚应舍）；原构置于第六、七分的两段文字，分别归入第七分、第八分；五眼一段归入第十八分。文句一仍原稿，仅改动承上启下的过接数处。
