# 润泽说 道可道之金刚经

《金刚般若波罗蜜经》三十二分的**完整通释**：一本可读、可查、可在手机上离线打开的书。

全书 **约 7.8 万字**：体例与总纲、三十二分正文、后记，另附五篇附录。

> 这本书的全部工作，只做一件事：**把「佛说 A — 即非 A — 是名 A」这把尺子，逐分拆开，让经文自己把般若讲出来。** 不取玄虚之说，不做宗教附会，落到「人如何不被自己的念头困住」。

## 一、体例：一分七段

| 段 | 做什么 |
|---|---|
| 原文底本 | 姚秦鸠摩罗什译本，通行字句，异读另注 |
| 分题释义 | 昭明太子三十二分标题的字面与义理；**逐分标明"标题非经"** |
| 字源与名相 | 梵文原词、汉译流变、古义勘正 |
| 逐段深解 | 本分核心义理，逐句落地 |
| 俗见勘破 | 三至五条常见误读，逐条正解 |
| 般若范式 + 跨典互参 | 三段论拆解；老庄、易传、儒门对照 |
| 小结 | 一段收束，接下一分 |

金刚经特有的一项：凡「如来说〇〇，即非〇〇，是名〇〇」句式，单列三层拆解——**随俗安立（佛说 A）／胜义破除（即非 A）／二谛圆融（是名 A）**。

底层模型为「三才五蕴太极空杯」与「佛说 A（阴）— 即非 A（阳）— 是名 A（太极）」。

**一处必须提前讲透**：「即非」不是否定，是不执。读成"其实没有这回事"，就滑向断灭空，废因果、废修行、废慈悲——这是本经自己反复警告的坑（"法尚应舍，何况非法"正为此设）。「即非」破的只是"把它当成固定实有的东西抓在手里"，不破它缘起的作用。

## 二、结构：三分判摄

- **序分**：第一分法会因由、第二分善现启请。
- **正宗分**：第三分至第三十一分。破四相、破法执、明无住、辨福德、显实相。
- **流通分**：第三十二分应化非真。

正宗分主线一句话：须菩提两问（云何应住、云何降伏其心），佛陀一路只答一件事——**应无所住而生其心**。二十九分，都是在从不同角度拆解"住"这个字。
